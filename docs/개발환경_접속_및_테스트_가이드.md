# 개발환경 접속 및 테스트 가이드

---

## 1. 프로필 구성

| 프로필 | DB | 용도 |
|--------|-----|------|
| `dev` (기본) | H2 인메모리 | 개발/테스트 |
| `local` | MySQL (localhost) | 로컬 MySQL 연동 |
| `prod` | MySQL (환경변수) | 운영 |

프로필 변경 방법:
- `application.yml`의 `spring.profiles.active` 값 변경
- 또는 실행 시 `--spring.profiles.active=local` 전달

## 3. MySQL 로컬 접속 (local 프로필)

### 3.1 사전 준비

MySQL에 root 계정으로 접속 후 아래 명령어를 순서대로 실행합니다.

```sql
-- 1. 데이터베이스 생성
CREATE DATABASE reportdb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 2. 계정 생성
CREATE USER 'docs'@'localhost' IDENTIFIED BY 'docs123';

-- 3. 권한 부여
GRANT ALL PRIVILEGES ON reportdb.* TO 'docs'@'localhost';

-- 4. 권한 적용
FLUSH PRIVILEGES;
```

### 3.2 기본 접속 정보

| 항목 | 값 |
|------|-----|
| Host | `localhost:3307` |
| Schema | `reportdb` |
| Username | `docs` |
| Password | `docs123` |

### 3.3 JPA 설정

- `ddl-auto: update` — 엔티티 기반으로 테이블 자동 생성/변경
- `show-sql: true` — SQL 로그 출력

## 4. 빌드 및 실행

```bash
# 컴파일
./gradlew.bat compileJava

# 실행 (dev 프로필, H2)
./gradlew.bat bootRun

# 실행 (local 프로필, MySQL)
./gradlew.bat bootRun --args='--spring.profiles.active=local'

# 테스트
./gradlew.bat test
```

## 6. H2 Console에서 수동 CRUD 테스트

H2 Console 접속 후 아래 SQL로 직접 CRUD를 확인할 수 있습니다.

```sql
-- 테이블 확인
SHOW TABLES;

-- Project 생성
INSERT INTO project (id_project, project_code, project_name, active, is_deleted, created_at, updated_at)
VALUES ('test-id-1', 'PRJ001', '테스트 프로젝트', true, false, NOW(), NOW());

-- Project 조회
SELECT * FROM project;

-- Repository 매핑 등록
INSERT INTO project_repository_map
(id_project_repository_map, id_project, repository_name, repository_url, default_branch, priority_order, active, is_deleted, created_at, updated_at)
VALUES
('map-id-1', 'test-id-1', 'api-server', 'https://github.com/example/api-server.git', 'main', 1, true, false, NOW(), NOW()),
('map-id-2', 'test-id-1', 'admin-server', 'https://github.com/example/admin-server.git', 'develop', 2, true, false, NOW(), NOW()),
('map-id-3', 'test-id-1', 'common-lib', 'https://github.com/example/common-lib.git', 'main', 3, true, false, NOW(), NOW());

-- Repository 매핑 조회
SELECT * FROM project_repository_map WHERE id_project = 'test-id-1' AND is_deleted = false;

-- Project 수정
UPDATE project SET project_name = '수정된 프로젝트' WHERE project_code = 'PRJ001';

-- 논리 삭제
UPDATE project SET is_deleted = true, deleted_at = NOW() WHERE project_code = 'PRJ001';

-- 물리 삭제
DELETE FROM project WHERE project_code = 'PRJ001';
```
