
# Auto Report Draft System – Spring Boot 구현 로드맵 (V3 기반)

목표:
V3 설계 문서를 기반으로 **자동 보고서 초안 생성 시스템**을 Spring Boot 프로젝트에 단계적으로 구현한다.
각 단계는 **구현 → 테스트 → 다음 단계** 방식으로 진행한다.

핵심 원칙
- 작은 단위로 구현
- 각 단계마다 테스트 수행
- 변경 이벤트(Change Event) 중심 설계 유지
- 보안 정책 준수 (민감 정보 저장 금지)

---

# 전체 구현 단계 개요

1. ✅프로젝트 기본 구조 생성
2. Project / Repository Mapping 구현
3. Analysis Request 시스템 구현
4. Git Analyzer 구현
5. DB Schema Analyzer 구현
6. API Analyzer 구현
7. Evidence 저장 구조 구현
8. Noise Filtering 구현
9. Change Event Builder 구현
10. Change Correlation Engine 구현
11. Draft Generator 구현
12. Markdown 보고서 생성
13. LLM 요약 모듈 (선택)
14. Runtime Analyzer 추가
15. 운영 기능 및 권한 관리
